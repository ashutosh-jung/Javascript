About me

I'm Ashutosh Jung Thapa, a fullstack developer working across React, Node.js, and MySQL to build products that solve real, everyday problems — from an adoption platform connecting shelters with adopters, to a professional site for a law firm, to a desktop tool for managing garment production.

I care about getting the fundamentals right: a data model that makes sense, an API that behaves predictably, and an interface that doesn't get in the user's way. I enjoy the full path from a rough idea to something people can actually open and use.

Outside the code itself, I focus on clear communication, breaking down hard problems into manageable steps, and making sensible decisions when requirements are unclear.
